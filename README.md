# Landing Page — Pupo Corretora de Seguros

Página de captação (landing page) **independente** do CRM, feita para conquistar/atender a Pupo Corretora.

## Como abrir
Basta abrir o arquivo `index.html` no navegador (duplo clique). Não precisa instalar nada — usa Tailwind via CDN.

## Antes de publicar (2 ajustes)
1. **WhatsApp**: no fim do `index.html`, troque a constante `WHATSAPP` pelo número real
   (formato internacional só com dígitos, ex.: `5511998887766`).
2. **Textos/números**: revisar estatísticas (anos, nº de clientes) e depoimentos com dados reais.

## Publicar de graça
- Arraste a pasta para o [Netlify Drop](https://app.netlify.com/drop) **ou**
- Suba no GitHub Pages / Vercel. É um site estático, sem build.

## Identidade
- Azul-marinho `#0d2440` + azul-claro `#3b9fe0` (baseado no Instagram @pupo.corretora).
- Fontes: Poppins (títulos) + Inter (texto).
- Logo "P" recriado em SVG (aproximação da marca).

Conteúdo baseado no perfil público @pupo.corretora (bio, serviços e linktree).
